# 毎日タロット＆占い

ブラウザだけで遊べる、4 つの占いをまとめた SPA(Single Page Application)。
GitHub Pages に置けば、URL を開くだけですぐ遊べます。

## 含まれる占い

| 占い | 概要 |
| --- | --- |
| 🃏 **タロット** | 78 枚のフルデッキ(大アルカナ 22 + 小アルカナ 56)。1 枚引き / 3 枚スプレッド(過去 / 現在 / 未来)、正逆位置ランダム |
| ᚠ **ルーン** | 古代北欧の 24 ルーン + 白紙の「ヴィルド」。3 つの石で状況 → 障害 → 助言 を鑑定 |
| ⛩ **おみくじ** | 大吉 〜 大凶の 7 段階を重み付きで抽選。願い事 / 仕事 / 健康 など 11 カテゴリのひとことも |
| ☯ **周易(易経)** | コイン 6 投げで 1 卦 + 変爻を構成。本卦と之卦の両方を表示 |

## 特徴

- **画像アセット 0 個**: カード・記号・卦はすべて SVG インライン描画
- **オフラインでも動く**: ネット帯域に依存しない
- **ダーク × 金 × 紫の神秘的な配色**、日本語 UI
- **履歴保存**: 結果は `localStorage` に保存され、リロードしても残る
- **アクセシビリティ**: `prefers-reduced-motion: reduce` でアニメ自動オフ
- **モバイル対応**: 375px までレイアウト崩れなし

## 技術スタック

- [Vite 5](https://vitejs.dev/) + [Preact 10](https://preactjs.com/) (`preact-iso` でハッシュルーティング)
- TypeScript
- CSS Modules(フレームワーク非依存)
- `crypto.getRandomValues` ベースのセキュアな Fisher–Yates シャッフル

## 開発

```bash
# 依存インストール
npm install

# 開発サーバ (http://localhost:5173)
npm run dev

# 型チェック
npm run typecheck

# 本番ビルド (dist/ に出力)
npm run build

# ビルド成果物のプレビュー
npm run preview
```

## デプロイ

`main` ブランチに push すると、GitHub Actions が `dist/` を GitHub Pages にデプロイします。

- リポジトリ Settings > Pages > Source: **GitHub Actions** を選択
- 公開 URL は `https://<user>.github.io/<repo>/` (サブパス対応済み)

## 占い方

### タロット

1. ナビから「タロット」を選びます
2. タブで「1 枚引き」か「3 枚スプレッド(過去 / 現在 / 未来)」を切り替えます
3. 「カードを引く」を押すと、シャッフル → 1 枚ずつめくられます
4. 結果に「正位置 / 逆位置」「キーワード」「解釈」が表示されます
5. 履歴タブで過去 30 件まで再閲覧できます

### ルーン

- 「3 つの石を引く」を押すと、白紙の石が順番に裏返り、各ルーンの文字が浮かび上がります
- 1 番目: 状況 / 2 番目: 障害 / 3 番目: 助言、として読みます
- 25 文字すべての意味は下部の一覧で確認できます

### おみくじ

- 「桶を振る」を押すと桶が揺れ、札が落ちてきます
- 結果は 7 段階(大吉 / 吉 / 中吉 / 小吉 / 末吉 / 凶 / 大凶)+ 11 カテゴリのひとこと

### 周易

- 「コインを 6 回投げる」を押すと、コインが 6 回振られ、各爻が決まります
- 6(老陰)と 9(老陽)が出ると「変爻」になり、本卦 → 之卦 への変化を示します
- 変爻が出た位置はハイライトされ、具体的なメッセージとして読み取れます
